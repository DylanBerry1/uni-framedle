# \# Frame Data Guessr

# This tool picks a random move out of the 1,556 moves in the game Under Night In Birth 2 \[sys-celes] and asks the user to guess the startup and frame advantage of each move. It was designed to help the user learn the different moves of the game, and as it is a fighting game, knowledge is crucial to winning. Knowing that a move is -6 and punishable on block can win you games, and is what this tool allows the user to learn.
